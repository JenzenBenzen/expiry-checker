# Expiry Checker

**Android App** to scan expiry dates from food packaging using the camera and OCR.  
Designed for visually impaired users with:

- Extra large text
- Big buttons
- Clear color feedback (green, orange, red)
- Support for older Android phones

## Features (planned)

- [ ] Camera access
- [ ] Text recognition via Google ML Kit
- [ ] Intelligent date parsing
- [ ] Color-coded expiry warning
- [ ] Super simple UI

## Tech stack

- Java
- Android SDK
- Google ML Kit (OCR)
